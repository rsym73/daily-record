# 原型：严格锁状态机（一次性，验证完即删）

**要验证的问题：** 严格锁的语义是否正确、有没有反直觉的边界——给定「模拟时钟 + 已完成天数 + 链起点」，系统如何判定：当前记录页日期、冻结、解锁、断链、连续天数、重置。

## 运行

```
python prototype/main.py
```

## 怎么玩

| 命令 | 作用 |
|------|------|
| `c` | 完成今天 |
| `c 2024-01-02` | 尝试完成指定天（用来验证「不能补写 / 不能提前写」） |
| `u` | 撤销今天的完成 |
| `r` | 重置（清除连续天数，保留历史） |
| `+1h` / `+1d` | 前进时钟 1 小时 / 1 天 |
| `set 2024-01-01 00:30` | 把时钟设到指定时间（并重新锚定链起点） |
| `q` | 退出 |

## 重点场景

1. `set` 到某天 **00:30** → 看「当前记录页」还是**前一天**；此时 `c` 完成的是哪一天。
2. `+1h` 跨过 **01:00** → 看前一天冻结、今天解锁。
3. 漏掉一天（不 `c` 直接 `+1d`）→ 看**断链**、连续天数**保留旧值并标红**、今天锁死 🔒。
4. `c 2024-01-03`（昨天或未来天）→ 看「不能补写 / 不能提前写」的拒绝。
5. `r` 重置 → 看历史保留（✓/·）、连续天数从今天重新起链。
