# 07 凌晨 1 点边界：冻结

## What to build

领域引擎实现「一天边界 = 凌晨 1 点（设备本地时区）」。跨过边界后，那天的记录页变只读（冻结），不能编辑、删除、完成或撤销。

## Acceptance criteria

- [ ] 领域引擎：给定时间与时区，能判定某天是否已冻结（跨过其凌晨 1 点边界）
- [ ] 冻结的记录页 UI 变为只读，不能编辑/删除/完成/撤销
- [ ] 「今天」按设备本地时区计算
- [ ] 测试穷举凌晨 1 点边界两侧、跨时区场景
